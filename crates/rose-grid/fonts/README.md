# Bundled font

`LiberationSans-Bold.ttf` — Liberation Sans Bold, SIL Open Font License 1.1.

Liberation Sans is metric-compatible with Arial (same character widths),
which is why fontconfig itself substitutes it for Arial requests. Axis
labels rendered with it are glyph-identical in metrics to Arial Bold and
equally OCR-friendly; Arial itself cannot be bundled (proprietary license).

Upstream: https://github.com/liberation-fonts
Also ships on the VM via the `fonts-liberation` apt package.
